# Zapbeam

Zapbeam is an open-source project building a desktop media optimizer for macOS and Linux, inspired by ImageOptim.

Its focus is simple: a minimal interface, responsive interactions, and efficient compression that balances quality and speed. Local-first operation keeps files on your machine, without accounts, uploads, or cloud processing.

Built with Tauri, React, TypeScript, and Rust.
